## Hi, I'm Midya

I'm a Toronto-based technologist with 12+ years across technology, financial services and telecommunications. These days most of my build time goes into large language models, agentic systems and workflow automation.

I learn things by building them from scratch, usually in NumPy, small enough to run on a laptop, with tests and an honest write-up of what worked and what didn't.

### A few things I've built

- [scratchgpt](https://github.com/midya8/scratchgpt): a GPT built and trained in pure NumPy, with its own tiny autograd and hand-written backprop.
- [ml-from-scratch](https://github.com/midya8/ai-portfolio): my monorepo of about 40 smaller builds, from a NumPy transformer and FlashAttention to RAG and agent tooling.
- [mamba-numpy](https://github.com/midya8/ai-portfolio/tree/main/mamba-numpy): a Mamba-style selective state-space model with backprop through the scan, and an experiment showing what "selective" buys.
- [mixture-of-experts](https://github.com/midya8/mixture-of-experts): sparse expert routing, load balancing and what happens when routing collapses.
- [speculative-decoding](https://github.com/midya8/speculative-decoding): draft-and-verify decoding that keeps the target model's output unchanged.
- [lora-finetuning](https://github.com/midya8/lora-finetuning): low-rank adapters on a frozen model, and how much rank you actually need.
- [evalforge](https://github.com/midya8/evalforge): local evaluation for LLM and agent outputs, with regression gates for CI.
- [agenttrace](https://github.com/midya8/agenttrace): validation, analysis and HTML reports for agent execution traces.

There's plenty more in my [repositories](https://github.com/midya8?tab=repositories), and the full list with write-ups is in my [portfolio](https://github.com/midya8/Midya-portfolio).
